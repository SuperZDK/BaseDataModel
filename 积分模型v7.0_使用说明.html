积分模型 v7.0 使用说明

PPG计算 · 线性过渡 · 六档判定 · 联赛梯队映射 — 分步详解

一、模型概览

积分模型 v7.0 是一个 基于PPG（Points Per Game，场均积分） 的球队实力比较模型。它的核心思路很简单：一支球队的水平最直接地体现在它每场比赛平均能拿多少分。

模型做两件事：

  1. 算出一个"有效PPG" — 综合上赛季和本赛季数据，给每支球队一个当前实力估计值
  2. 比较两队有效PPG的差距 — 将差距映射到6个档位，告诉你这个差距有多大、属于什么水平

模型不预测比分，不给出投注建议。它只量化"这两队之间有多大的实力鸿沟"。

二、核心概念：PPG

PPG = 积分 ÷ 场次。比"总积分"更公平，因为各队赛程进度可能不同。

举例

球队A：18场42分 → PPG = 42 ÷ 18 = 2.333

球队B：18场17分 → PPG = 17 ÷ 18 = 0.944

球队A每场多拿约1.39分，38轮等效分差 ≈ 53分

三、先验PPG 与 当前PPG

PPG由两个部分合成：

3.1 先验PPG

先验PPG = 上赛季积分 ÷ 38

这是赛季开始前对该队实力的初始估计。用上赛季的总积分除以固定38轮。

  • 已在上赛季英超的球队：直接取上赛季最终积分 ÷ 38。例如曼城上赛季84分 → 先验PPG = 2.211
  • 升班马（上赛季不在英超）：上赛季积分为0，先验PPG无法直接用。模型在R≤10时自动使用"升班马参照PPG"（默认1.05，来自近年升班马平均表现）。R>10后升班马已有足够数据，参照自动失效，先验PPG归0。

为什么用先验？因为赛季初（前4轮）本赛季数据太少，仅凭2-3场的PPG可能完全失真（比如某队前3轮对手全是强队全输了，PPG=0，但这不代表它是保级队水平）。先验起到了"拉回合理区间"的作用。

3.2 当前PPG

当前PPG = 当前积分 ÷ 已赛场次

本赛季的实际表现，你每轮更新一次积分和场次即可。

  • 通常赛季进行到一半时，当前PPG已经很有说服力
  • 但如果两队已赛场次差距过大（比如主队踢了18场，客队只踢了14场），需要留意 ⚠️ 场次差 标记

四、线性过渡：如何合成有效PPG

有效PPG是 先验PPG 和 当前PPG 的加权平均，权重随轮次变化：

轮次先验权重当前权重含义
R1 ~ R4100%0%完全依靠上赛季印象
R580%20%本赛季数据开始加入，但只占小头
R660%40%五五开过渡
R740%60%本赛季开始主导
R820%80%接近全用本赛季
R9+0%100%完全使用本赛季数据

公式：

if R ≤ 4: 有效PPG = 先验PPG

else: weight = max(0, 1.0 - (R-4) × 0.2)

有效PPG = weight × 先验PPG + (1-weight) × 当前PPG

过渡示例
某队先验PPG=2.211（上赛季第2），前8轮拿了10分（当前PPG=10÷8=1.250），第8轮时：
weight = max(0, 1.0 - (8-4)×0.2) = max(0, 0.2) = 0.2
有效PPG = 0.2×2.211 + 0.8×1.250 = 0.442 + 1.000 = 1.442
解释：前8轮表现确实不佳（1.250），但上赛季的底子在R8时仍保留20%的权重，有效PPG为1.442，介于两者之间。到第9轮以后先验权重归0，有效PPG=当前PPG=1.250。

五、六档强弱判定

比较两队有效PPG，计算分差，然后归档。

PPG差 = 主队有效PPG − 客队有效PPG

边界规则：遇到边界值时向上取整。例如PPG差=0.12，归档到档2（略优）；PPG差=0.30，归档到档3（较优）。

说明：梯队差距是对档位的实际比赛含义的解释，不是精确一对一的数学映射。档位基于两队PPG差判定，梯队基于每队绝对PPG定位。两者之间存在约半个档位的自然偏移（例如争冠vs欧战理论跨约2个梯队，但PPG差约0.68落在档4区间），这是由梯队PPG范围边界重叠导致的正常现象。

归档示例
主队有效PPG = 2.211，客队有效PPG = 0.895
PPG差 = 2.211 − 0.895 = 1.316
1.316 > 1.10 → 档5，标签"超优偏主"
38轮等效分差 = 1.316 × 38 ≈ +50分
梯队差距：争冠级 vs 保级挣扎级，差3+个梯队 → 对照表 → 断档级差
归档示例2（客队优势）
主队有效PPG = 1.050，客队有效PPG = 1.350
PPG差 = 1.050 − 1.350 = −0.300
abs(0.300) → 归档档3，标签"较优偏客"
38轮等效分差 = −0.300 × 38 ≈ −11分
梯队差距：保级挣扎 vs 中游，跨约1.5个梯队 → 对照表 → 跨2个梯队

七、输出解读

在综合模型中，积分模型的输出以以下形式展示：

7.1 积分档位徽章

彩色徽章直接显示档位编号和简称：

档0 同分 档1 同等 档2 略优 档3 较优 档4 明显 档5 超优

7.2 有效PPG数值

两队各自的`有效PPG`精确到小数点后3位，分别以蓝色（主）和红色（客）显示。这个数值就是经过线性过渡后的最终PPG，直接用于计算分差。

7.3 详细过程文字

灰色底色的文字区域逐行列出了积分模型的关键中间值：

  • 档位标签和方向（偏主/偏客/=）
  • 等效38轮分差
  • 先验PPG和当前PPG（分别显示，方便你判断"当前表现是否跟上赛季有差异"）
  • 升班马标注（如适用）
  • 场次差 ⚠️ 标记（如适用）

七、需要留意的情况

8.1 两队已赛场次不等

当场次差≥2时，工具自动显示 ⚠️ 场次差=3 标记。提示当前PPG的可比性下降——赛程进度不同可能导致PPG被高估或低估。

例子：主队踢了18场（42分，PPG=2.333），客队踢了15场（35分，PPG=2.333），PPG相同但客队少踢了3场。如果客队后面3场对手都不强，其实际水平可能略高于主队。

8.2 升班马

上赛季积分=0的球队。赛季初（R≤10）使用参照PPG（默认1.05）作为先验。这个值相当于英超保级挣扎区（14-17名）中游水平。

如果你认为当年升班马整体较强或较弱，可以手动调整"升班马参照PPG"值。默认1.05是基于近4季数据的均值。

8.3 赛季初（R≤4）

完全使用先验PPG。这时的"档位"反映的是上赛季的实力对比。比如前4轮的曼城vs诺维奇，即使曼城开局2连败，模型仍然认为曼城远强于诺维奇——因为4场数据不足以推翻上赛季的结论。

8.4 赛季末（R≥30）

完全使用当前PPG。此时的"有效PPG"已经和你直接看积分榜几乎一致，但多了一个"档位"的归一化标签让你快速判断差距量级。

八、常见问题

PPT差档位和"联赛梯队"有什么区别？

档位是两队的相对差距，梯队是每队的绝对位置。档5可能由争冠vs降级产生（梯队差4），也可能由欧冠vs保级产生（梯队差3）。梯队映射是一个额外参考，帮你理解这个档位的实际比赛含义。

升班马参照值能改吗？怎么知道该改多少？

可以改。默认1.05是近4季英超升班马PPG均值。如果你当年统计发现升班马整体PPG有显著差异（比如当季3支升班马都很强或都很弱），可以手动调。具体值需要你自己查数据。

为什么用38轮等效分差？

PPG是小数值（0~3之间），不够直观。乘以38轮后变成"一个赛季的总分差距"，更贴近日常看积分的习惯。比如"档4 = ±23~42分"，你会立刻意识到这差不多是"曼城比阿森纳多拿30分"的概念，比"PPG差0.79"更直观。

连续两年升班马（如诺维奇这种来回升降级的）怎么处理？

填上赛季积分=0即可。升降机球队在R≤10时会获得参照PPG（1.05）作为先验。如果该队实际水平明显高于普通升班马（比如它本身就是来回升降级的熟客），你可以手动调高参照值。

模型能处理中途扣分（如埃弗顿2023被扣10分）吗？

不能自动处理。被扣分是联赛官方处罚，不是球队实力问题。如果你认为扣分扭曲了当前PPG，请在输入"当前积分"时使用扣分前的实际比赛积分。工具只按你填入的数字计算。
