综合模型 v3.0 使用说明

积分模型 v7.0 + 近期战绩模型 v1.0 — 分步操作指南

一、工具概述

综合模型 v3.0 是一个英超比赛分析工具，它将 积分模型（基于全赛季PPG判断球队长期实力差距）和 近期战绩模型（基于近4场结果判断短期状态）合并展示。

你输入两队的基本数据，工具自动计算并在同一屏幕展示两行综合结果：第一行是矩阵判定的方向，第二行是积分和战绩的具体情况。所有计算逻辑封在工具内部，你在网页上直接操作，不需要手动查表。

二、输入数据详解

2.1 主队 / 客队 信息卡

左右两栏结构，主队和客队的输入项完全对称。以下以主队为例说明。

输入框 ①
队名（选填）
仅用于结果显示中标注是哪支球队。不填写时工具自动显示"主队"或"客队"。不影响任何计算。
示例：曼城
输入框 ②
上赛季积分
上赛季英超总积分。用于计算"先验PPG"，即赛季开始前对该队实力的初始估计。

升班马（上赛季在英冠，无英超积分可查）：填 0。工具会在R≤10时自动使用"升班马参照PPG"（默认1.05）作为先验。R>10后升班马参照不再生效，完全依赖本赛季实际数据。
示例：曼城上赛季84分 → 填 84。升班马 → 填 0。
输入框 ③
当前积分
本赛季截至当前轮次的累计积分。用于计算"当前PPG"。
注意：填的是 总积分，不是场均分。例如前18轮拿了42分就填42。
示例：利物浦18轮42分 → 填 42。
输入框 ④
已赛场次
本赛季已踢的联赛场次数。用于将当前积分转为PPG（当前积分 ÷ 已赛场次 = 当前PPG）。
如果本场是第19轮且都踢了，已赛场次 = 当前轮次 - 1（如果当前轮已踢完则 = 已赛场次 = 当前轮次）。实际上，只要填你查到的该队真实已赛场次即可。
示例：第19轮，两队都踢了18场 → 填 18。
下拉菜单 ⑤
近4场（近1 / 近2 / 近3 / 近4）
该队最近4场联赛的结果，从近1（最近一场）到近4（4场前），按时间倒序排列。

每场三个选项：
  • 胜 — 该场赢球，赋值5分
  • 平 — 该场打平，赋值2分
  • 负 — 该场输球，赋值0分
工具将4场得分相加得到该队的"战绩分"（范围0~20）。积分模型用战绩分差=主队总分-客队总分来判断短期状态优劣。
示例：最近4场胜负负胜 → 近1=胜, 近2=负, 近3=负, 近4=胜

2.2 全局参数

输入框 ⑥
当前轮次 (R)
当前比赛的轮次。决定了积分模型中"先验PPG"和"当前PPG"的权重分配：
  • R ≤ 4：完全使用先验PPG（上赛季数据），本赛季数据太少，不可靠
  • R = 5：80%先验 + 20%当前
  • R = 6：60%先验 + 40%当前
  • R = 7：40%先验 + 60%当前
  • R = 8：20%先验 + 80%当前
  • R ≥ 9：完全使用当前PPG（本赛季数据已足够）
同时 R 也控制升班马参照PPG是否生效（仅R≤10时有效）。
示例：第19轮比赛 → 填 19
输入框 ⑦
联赛总轮次
英超固定为38。用于将PPG换算为38轮等效分差。不需要改。
固定值：38
输入框 ⑧
升班马参照PPG（R≤10生效）
给升班马（上赛季积分=0的球队）使用的先验PPG默认值。

原理：升班马上赛季不在英超，没有英超积分数据。如果R≤10，工具用这个值作为他们的"先验实力估计"，避免赛季初被低估。

默认值1.05来自英超升班马的历年平均水平（约等于保级挣扎区中游）。通常不需要改，除非你有特定赛季的统计想自己试。

R>10后升班马已有至少11场数据，该值自动失效，先验PPG归0。
默认值：1.05

三、输出结果解读

点击"计算综合输出"按钮后，结果区域从上到下依次展示以下几部分：

3.1 对阵表头

显示"主队名 VS 客队名"，来自你填的队名。仅做标识，无计算结果。

3.2 综合输出（两行核心结果）

第1行：矩阵方向（附加说明）

  • 前半部分是矩阵综合判定，共9级：主巨大 / 主明显 / 主优势 / 倾向主 / 均势 / 倾向客 / 客优势 / 客明显 / 客巨大
  • 后半部分括号内是附加说明，取决于积分是否有差距：

第2行：积分情况 | 战绩情况

  • 积分[等级] — 来自积分模型档位名：超优（档5）、明显（档4）、较优（档3）、略优（档2）、同等（档1）、同分（档0）
  • 战绩[优劣] — 来自战绩模型分差的等级：巨大优势/明显优势/优势/轻微优势/均势/轻微劣势/劣势/明显劣势/巨大劣势
  • 末尾如有 ⚠ — 表示积分优势方的战绩方向与积分方向相反，产生冲突

两种显示模式：

模式A：积分有差距（档位2~5）

括号内显示积分优势方的队名。第2行显示该队的积分等级和战绩优劣。

主巨大（曼城）
积分超优 | 战绩巨大优势
✓ 曼城积分超优（档5），战绩也是巨大优势，方向一致，无⚠
均势（曼城） 乱
积分超优 | 战绩巨大劣势 ⚠
⚠ 曼城积分超优但战绩巨大劣势，方向严重冲突，矩阵判定为混乱
模式B：积分均势（档位0~1）

括号内显示"积分均势"。第2行显示主队的战绩情况。

主优势（积分均势）
主队战绩优势
✓ 两队积分接近，但主队近4场状态占优，矩阵判定倾向于主
客巨大（积分均势）
主队战绩巨大劣势
✓ 积分均势，但主队近4场惨淡，矩阵判定为客巨大

3.3 标记区（第2行下方）

可能出现以下圆角标签，每个标签一种颜色，一眼可知：

标记含义何时出现怎么处理
乱 矩阵判定为"混乱" 积分方向与战绩方向严重冲突，矩阵无法给出明确方向 说明这场比赛两个模型指向完全相反，建议你结合其他信息手动分析
[++] 双高 两队近期状态都很好 两队近4场得分均≥15（即至少3胜或2胜2平） 比赛可能进账比较多，双方都在状态
[--] 双低 两队近期状态都很差 两队近4场得分均≤5（即4场最多1胜或1平3负） 比赛可能沉闷或不确定性高，两队都在低迷期
⚠️ 场次差=3 两队已赛场次差距≥2 如主队踢了18场、客队踢了15场，场次差=3 当前PPG的可比性降低。场次差越大，PPG数据的时效性差异越明显

3.4 积分档位与PPG数值

显示两队有效PPG（经过线性过渡后的最终PPG值）和积分档位（0~5的彩色徽章）。这些是积分模型的原始计算结果。可以作为调试参考。

3.5 详细计算过程

最下方灰色文字区域，逐行展示积分模型和战绩模型的详细中间值，包括：

  • 积分模型：档位、等效分差、先验PPG、当前PPG、升班马标注
  • 战绩模型：每场胜负中文显示、总分、分差、战绩等级
  • 综合输出：两行结果的文字副本

四、完整操作流程示例

示例：曼城 vs 诺维奇（第19轮）

步骤1：填主队信息
队名：曼城
上赛季积分：89（夺冠赛季积分）
当前积分：44（19轮44分）
已赛场次：18
近4场：近1=负, 近2=负, 近3=负, 近4=负（4连败）
步骤2：填客队信息
队名：诺维奇
上赛季积分：0（升班马）
当前积分：12
已赛场次：18
近4场：近1=胜, 近2=胜, 近3=胜, 近4=胜（4连胜）
步骤3：填全局参数
当前轮次：19
联赛总轮次：38
升班马参照PPG：1.05（默认，R=19>10不生效）
步骤4：点击"计算综合输出"

预期输出：

主优势（曼城）
积分超优 | 战绩巨大劣势 ⚠

解读：

  • 矩阵判定为"主优势"——虽然曼城4连败，但积分超优（档5）压住了短期状态劣势，矩阵倾向主
  • 但⚠标记提示：积分优势方（曼城）的积分超优和战绩巨大劣势是方向冲突的
  • 这意味着曼城实力确实强于诺维奇，但近期状态极差，诺维奇反而势头正猛
  • 结论是"方向冲突"——建议你结合伤病、赛程等信息做人工判断

五、常见问题

Q1：两队已赛场次不同怎么处理？

直接填各自的实际场次即可。工具会分别计算各队的PPG。当场次差≥2时，自动显示 ⚠️ 场次差标记，提示两队数据可比性下降。

Q2：升班马的第一场英超比赛怎么填？

已赛场次填0，当前积分填0，上赛季积分填0。工具在R≤4时会完全使用升班马参照PPG（默认1.05）作为有效PPG。

Q3：中途换帅的球队怎么处理？

综合模型不做换帅专项处理。换帅的影响会体现在近4场战绩中——如果换帅后战绩明显改善，战绩模型会捕捉到。积分的长期实力部分则需要多场比赛才能体现变化。

Q4：输出结果中的"乱"和"⚠"有什么区别？

  • 乱：矩阵判定层面的标记。当积分方向与战绩方向冲突到矩阵无法给出明确判断时，矩阵输出"均势"并打上"乱"标签
  • ⚠：注释层面的标记。当积分优势方的战绩方向与积分方向相反时（即使矩阵还能给出方向），在注释行末尾加⚠提示
  • 两者可能同时出现，也可能只出现其中一个

Q5：这个工具能直接告诉我"买谁赢"吗？

不能。综合模型的设计初衷是展示信息，不是给出投注建议。两个模型独立展示，冲突情况用⚠标注，最终由你做决策。工具的目标是量化你的思考过程，不是替代你的判断。
